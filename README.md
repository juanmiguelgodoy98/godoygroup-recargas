# Recargas Saldo Móvil Cuba

Sitio web para la venta de recargas de saldo móvil en Cuba. Publicado con GitHub Pages.

🔗 https://juanmiguelgodoy98.github.io/godoygroup-recargas/

## ✨ Características

- Selección de ofertas de saldo con distintos montos y precios en CUP
- Cálculo automático del total a pagar según la oferta y cantidad elegida
- Validación del número de teléfono a recargar
- Métodos de pago: Transfermóvil y EnZona
- Botón para copiar los datos de transferencia
- Envío de la solicitud de recarga (con comprobante) directo por WhatsApp
- Alternativa por llamada o mensaje de texto para clientes sin internet
- Sección de promociones/concursos periódicos

## 🛠️ Tecnologías

- HTML, CSS y JavaScript (sitio estático)
- Hosting: GitHub Pages

## 📖 Cómo funciona

1. El cliente introduce el número a recargar.
2. Elige la oferta de saldo que quiere.
3. Ve el total a pagar, calculado automáticamente.
4. Selecciona el método de pago y copia los datos de transferencia.
5. Envía la solicitud junto con la captura de la transferencia por WhatsApp.
