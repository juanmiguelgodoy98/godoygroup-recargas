# Recargas Saldo Móvil Cuba

Sitio web para la venta de recargas de saldo móvil en Cuba, con cálculo automático de precios y flujo de pago vía Transfermóvil/EnZona.

🔗 **Demo en vivo:** https://juanmiguelgodoy98.github.io/godoygroup-recargas/

## ✨ Características

- Selección de ofertas de saldo con precios en CUP
- Cálculo automático del total a pagar según oferta y cantidad
- Validación del número de teléfono a recargar
- Métodos de pago: Transfermóvil y EnZona, con copiado de datos al portapapeles
- Envío de la solicitud (con comprobante) directo por WhatsApp mediante deep links
- Alternativa de contacto por llamada/SMS para clientes sin internet
- Sección de promociones dinámicas

## 🛠️ Tecnologías

- HTML, CSS y JavaScript (vanilla, sin frameworks)
- Diseño responsive
- Hosting: GitHub Pages

## 💡 Habilidades demostradas

- Manipulación del DOM y manejo de eventos en JavaScript puro
- Lógica de cálculo dinámico de precios
- Integración con WhatsApp vía URL schemes
- Validación de formularios en el cliente
- Despliegue y configuración de GitHub Pages
